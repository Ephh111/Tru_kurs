Сервер обработки векторов

Возможности программы

  • Проверка паролей с помощью хеш-функции SHA-1.
  • Чтение базы логинов и паролей из текстового файла.
  • Работа с сетью через сокеты.
  • Вычисление среднего значения для векторов из 16-битных чисел.
  • Запись логов работы сервера в файл.

Сборка проекта

Проект собирается с помощью утилиты make. В папке с проектом нужно выполнить команду: make

Для очистки скомпилированных файлов используется: make clean

Параметры командной строки:

  • -h или --help — вывод справки.
  • -f <путь> — путь к базе клиентов (по умолчанию /etc/vcalc.conf).
  • -l <путь> — путь к журналу (по умолчанию /var/log/vcalc.log).
  • -p <номер> — порт сервера (по умолчанию 33333).

Пример запуска: ./server_kurs -p 33333 -f vcalc.conf -l vcalc.log
